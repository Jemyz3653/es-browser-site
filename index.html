Features
/ 01

Fast by default

Минимальный оверхед, быстрый старт, отзывчивый UI. Никаких фоновых процессов, о которых вы не просили.

/ 02

Privacy first

Никакой телеметрии и аналитики. Ваша история остаётся вашей — браузер ничего не отправляет на сторону.

/ 03

Lightweight

Маленький размер, экономный к ОЗУ. Подойдёт даже для старых машин и слабых конфигураций.

/ 04

Open source

Полностью открытый исходный код. Изучайте, форкайте, дорабатывайте — браузер ваш.
